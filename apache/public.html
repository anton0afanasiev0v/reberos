Лаборатория Kerberos: публичная страница

Эта страница (/public) доступна без аутентификации — так проверяется, что веб-сервер вообще работает.

Основная страница сайта — / — защищена аутентификацией Kerberos (SPNEGO/GSSAPI): без билета она отдаёт HTTP 401.

Как получить доступ к / с хоста

  1. В /etc/hosts хоста: 127.0.0.1 web.lab.test.
  2. Настроен /etc/krb5.conf хоста (realm LAB.TEST, kdc = 127.0.0.1).
  3. kinit alice (пароль — из .env лаборатории).
  4. Браузер с поддержкой Negotiate на Linux — Firefox (network.negotiate-auth.trusted-uris = web.lab.test).

Подробности: docs/docker-lab.md, раздел «Доступ к сайту с хоста».
